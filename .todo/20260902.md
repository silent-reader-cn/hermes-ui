## [已收口] #41 [方向类·手势状态机] 聊天底部跟随取消时机重构——触摸即解锁，松手按方向/按压前状态定夺

- 类型：方向类（行为状态机重构）+ 问题类（现状「一碰就丢跟随」）。
- 位置：
  - 消息列表状态：`lib/features/chat/widgets/chat_message_list.dart`（`ChatMessageListState`：`_userHasScrolled` / `_nearBottom` / `_isUserInteracting`；贴底阈值 `_nearBottomThreshold=80`）
  - 手势/滚动通知链：`NotificationListener<ScrollNotification>`（原 :1390-1463）
- 术语约定（主人 2026-09-01 拍死）：一律以**内容方向**命名——「向上滑」= 手指从上往下滑，内容向上（朝底部/新内容，pixels 增大）；「向下滑」= 手指从下往上滑，内容向下（朝顶部/历史，pixels 减小）。
- 现状（取消跟随全清单）：`_onScroll` 位置离底 >80px 无方向判断即取消；`UserScrollNotification forward`（向底部方向）反而取消；拖拽 `delta.dy>0` 取消；非拖拽 `scrollDelta<-1.0` 取消——**一碰就丢、方向自相矛盾、砍了不回头**。
- 预期（主人已拍板全口径）：新状态机（两段式：拖动开始解锁 → 松手按方向/按压前状态定夺）。
- 实现（`f408e8c`）：
  - 状态记录：`_pressFollowed`（按压前跟随态）、`_dragDisplacement`（累计位移，内容方向）、`_dragSensitivityThreshold=8.0`（8px 排除轻点）
  - 拖动起始解锁：位移达 8px 即置 `_userHasScrolled=true` 解锁自由滚动。
  - 松手定夺（`_handleGestureEnd`）：累计**向上滑**（>8px，朝底部）→ 按压前跟随则恢复；按压前不跟随则近底（<80px）进入跟随，否则保持；累计**向下滑**（<-8px，朝顶部）→ 一定取消；**无位移/轻点** → 状态回按压前（不改变）。
  - 清理旧冲突逻辑：移除 `UserScrollNotification forward` 反向误取消、`delta.dy>0`、非拖拽 `scrollDelta<-1.0` 取消。
  - 非手势守卫扩展：（`_onScroll`）键盘/输入栏挤压/窗口 resize/新消息/程序滚动一律不置 `_userHasScrolled=true`
  - 主动导航例外：`outlineJumpTo` / `_scrollToHighlight` 离底即置（用户主动取消）。
  - 发送/Steer：普通发送走 `ChatPhase.sending` 复位跟随；Steer 发送不触发自动跟随、先前跟随保持。
- 验收结果：
  1. 跟随中：向上拖动（松手仍近底）→ 保持跟随；向下拖动 → 取消
  2. 不跟随中：向上拖动接近底（<80px）→ 恢复跟随；否则保持；轻点/无位移 → 状态不变
  3. 新消息/键盘/布局挤压/窗口 resize/程序滚动 → 不取消跟随
  4. 大纲跳转/高亮定位 → 离底不跟随（主动导航例外）
  5. 发送新消息 → 进跟随；steer 请求发出 → 不进跟随、先前已跟随则保持
