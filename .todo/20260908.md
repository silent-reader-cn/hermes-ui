## #100 锁屏久置解锁后 live chat 静默死透 [已收口 2026-09-08 @ 1966afe]

- 现象（主人报告）：锁屏时间久后解锁，live chat 不自动恢复；诊断日志筛 W/R 级最近一小时为零条（watchdog 完全沉默，区别于 #99 成串刷屏）。
- 根因（四重，均带源码行号实证）：
  - R1 重连预算 6 次（`maxReconnectAttempts`，`chat_providers.dart`）+ 退避 1+2+4+8+16+30s≈61s 烧尽后全链路静默：`_handleTransportError` WARN 后 return，watchdog 直接 return 零日志，`_forceReconnect` WARN 后 return——「最近一小时无 W/R」的直接根源。
  - R2 recovery 闩锁：transport error 置 checking 后预算烧尽无人复位，#29 解锁主动探活前置 `recovery == idle` 被永久跳过 → 解锁也救不回（死锁闭环）。
  - R3 解锁探活 one-shot：解锁瞬间网络未就绪 → 失败即转 forceReconnect 白烧预算，无重试。
  - R4 onClosed 不复位 recovery（静默断开族闩锁）。
- 交付（main @ 1966afe，5 文件 +538/-6）：
  - F1 resumed 重置恢复状态：解锁 = 人类在场 → `_reconnectAttempts=0` + 退避定时器清理 + recovery 非 idle 复位 idle + fullReconnect 冷却重置。
  - F2 解锁探活重试：`resumeProbeRetries=2` 次、间隔 `resumeProbeRetryDelay=2s`，重试耗尽才回退强连；watchdog 轮询路径不受影响。
  - F3 预算耗尽哨兵：`recoverySentinelInterval=60s` 周期 WARN `Recovery exhausted, re-probing` + `isThrottledFallback` 探活自愈（失败不重建流），探活成功自动解除并自毁；`_finishStream`/dispose 同步撤哨兵。
  - F4 onClosed 复位 recovery 闩锁（非完成态）。
  - 配置：`ChatWatchdogConfig` 新增 `recoverySentinelInterval` / `resumeProbeRetries` / `resumeProbeRetryDelay`（测试可 override）。
  - 测试：新增 `chat_recovery_exhaustion_test` 6 用例（F1 烧尽死锁解锁自愈 / 幂等 / F2 重试成功 / 重试耗尽回退 / F3 哨兵 WARN+自毁 / F4 onClosed 复位）；旧契约 `chat_reconnect_backoff_test`「达上限彻底躺平」更新为「startStream 封顶 + 哨兵周期探活」。
- 验收：`flutter analyze` 零告警；全库 2574 过（唯一挂 #90 已知 flaky，单跑复绿）；金照无变更。
- 待主人真机复验：锁屏 ≥10 分钟 → 解锁 → live chat 自动恢复；诊断日志应出现 `Resume active-probe triggered` / `Recovery exhausted, re-probing` 记录（修复前为纯静默）。
